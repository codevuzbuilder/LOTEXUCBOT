# 🛒 PUBG UC Shop Telegram Bot

Telegram orqali PUBG UC (valyuta) sotish va balansni to'ldirishga mo'ljallangan to'liq avtomatlashtirilgan do'kon boti (`aiogram` 3-versiya asosida yozilgan).

## ✨ Asosiy imkoniyatlari

* **💎 UC Sotib olish:** Foydalanuvchilar o'z balansidagi mablag' evaziga PUBG UC paketlarini xarid qilishlari va PUBG ID raqamlari orqali buyurtma berishlari mumkin.
* **💳 Hisobni to'ldirish:** 
  * Telegram Stars (`XTR`) orqali avtomatik to'lov.
  * Karta raqamiga pul o'tkazib, to'lov chegini yuborish (Admin tasdiqlashi uchun).
* **✨ Premium Emojilar va Dizayn:** Botdagi barcha tugmalar, matnlar va ranglarni o'zgartirish, shuningdek oddiy emojilarni avtomatik premium emojilarga o'tkazish imkoniyati.
* **📢 Majburiy obuna:** Botdan foydalanish uchun homiy kanallarga obuna bo'lish sharti.
* **👥 Referal tizimi:** Do'stlarini taklif qilgani uchun bonus berish va eng faollar reytingi (Top).
* **👮 Admin Panel:** 
  * Buyurtmalar va to'lovlarni tasdiqlash/rad etish.
  * UC paketlari va kanallarni boshqarish.
  * Foydalanuvchilarga xabar yuborish (Broadcast) va balansni o'zgartirish.
